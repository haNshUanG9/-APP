# 五线谱识谱 1.5.6 · 平板修正版

本版针对 1.5.5 实际界面中的谱行裁切、音符染色、提示不完整和报告分散等问题进行修正。面向 Android 10 及以上平板，沿用原包名与签名，可覆盖安装此前同签名版本。

## 看谱：完整、清楚，音符保持黑色

| 场景 | 相比 1.5.5 的变化 |
| --- | --- |
| 阅读钢琴双谱表 | 按完整谱行显示与翻动，避免窗口底部只露出下一行的一半；根据横竖屏及键盘状态安排一行或两行 |
| 左右手区分 | 谱面音符统一保持黑色，左右手颜色只用于琴键、标签和图例；左手绿、右手琥珀 |
| 跟随播放 | 使用浅色小节底和游标指示位置；关闭键位提示后仍能看清播放进度 |
| 查看错音 | 使用谱行底部的小圆点标记问题，符头不染色；复盘中点击具体位置可直接返回对应谱面 |
| 选段结束 | 播放 1—2 小节结束后停在第 2 小节，避免界面误显示第 3 小节 |
| 操作布局 | 横屏将曲名、模式和设置集中到一层顶栏；竖屏分两行排列；曲库和设置使用临时面板 |

模式、手别和设置切换时的重复控件与排谱失败也已修复。原谱与 MIDI 的排谱、练习目标和音符时值继续使用正式排谱及训练模块。

## 练习：减少干扰，提示能完整读到

- 修复记忆提示只显示切换按钮、正文被高度限制裁掉的问题；提示按内容占用空间，参照音和当前目标有明确标识。
- 独立认音阶段的课程标题不再提前显示目标音名。需要帮助时仍可主动查看分层提示，用过帮助的音单独记录。
- 在不限时认音中，仅打开主菜单再返回当前题，不再被记为训练中断。真正暂停、离开训练或进入后台仍保留中断记录；计时、听音和播放中的菜单操作仍会暂停。
- 专项局部键盘按本组候选范围安排，避免固定音区把题目所需琴键排到画面外；需要横向移动时显示左右按钮和滑动说明。
- 统一节奏双侧按钮、琴键与左右手标签的颜色，调整结果和 MIDI 面板中遗留的背景色。
- 专项练习继续保留“弹对、松键后连续 1 秒无新输入自动继续”；新题等待输入后再计时。

## 复盘：先知道这一轮发生了什么

首屏明确区分完整完成、提前结束、含中断和借助帮助，再显示独立正确、借助帮助和待检查的数量。学习模式的“本轮独立认准率”以全部已评估音为分母：例如 4 音中 3 音独立正确、1 音用过帮助，显示 75%，避免局部样本的 100% 掩盖帮助记录。训练和复习判定规则保持原有证据标准。

每轮优先呈现一个可执行的下一步，减少重复重练按钮和相互冲突的建议；提前结束时不据此判断能力。逐音记录、统计说明和节奏回放可在详情中展开。结果页增加边距，曲谱报告增加“返回谱面”。

“进步记录”新增统一练习列表，集中查看课程、专项与短句、节奏、曲谱和自由识谱记录，可按训练类型和屏幕琴键／实体琴筛选。各类训练仍分别评价，原分类记录与复习安排保留在展开区域。

## 安装与下载

从 [1.5.6 Release](https://github.com/haNshUanG9/piano-sight-reading/releases/tag/v1.5.6) 下载：

- `piano-sight-reading-1.5.6.apk`：安卓安装包。
- `piano-sight-reading-1.5.6.html`：独立离线网页，可在电脑浏览器打开。
- `CHANGELOG-1.5.6.zh-CN.md`：本更新说明。
- `SHA256SUMS.txt`：附件校验值。

覆盖安装会保留原应用数据；也可先在应用内导出备份。HTML 与 APK 的本机数据分别保存。MIDI、MusicXML、MXL 导入，分段路线、到期复习、18 课入门课程、节拍器和 30 个离线钢琴采样继续保留。MIDI 不识别真实手指或手型，缺失的指法不会自动猜测。

## 验证范围

桌面 Chrome 自动化覆盖 1280×800、1440×900、800×1280，检查实际生产界面、黑色音符、完整谱行、键盘展开／收起、提示正文、报告、菜单返回、练习记录、考核提示隔离、1 秒自动继续和模拟 MIDI。使用实际 96 小节 MIDI、MusicXML 及压缩 MXL 检查导入与定位。APK 校验签名、对齐和内嵌页面；离线采样与许可声明保留。

本版尚未在真实安卓平板和实体 MIDI 钢琴上实测，设备触控、USB 连接与音频延迟仍需实机验证。
