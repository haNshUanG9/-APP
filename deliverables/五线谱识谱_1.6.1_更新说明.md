# 1.6.1 · MSCZ 导入与调号认音（测试版）

本版在 1.6.0 的曲库和认音训练中加入 MuseScore 原文件导入、调号影响与记忆迁移。以 GitHub 测试版（Pre-release）提供，继续验证真实平板体验。

## 新增：直接练自己写的谱

- 曲库支持导入 `.mscz` / `.mscx`，在本机读取，不需要联网转换；保留原有 MIDI、MusicXML、MXL 导入。
- 谱面与练习事件分别处理，保留调号、拍号、谱号、符值、附点、三连音、指法、延音、圆滑线、连梁和表情文字。跨声部延音不再被错误地当成新的按键目标。
- 新增“保真检查”，列出具体符号或片段的限制，点击可定位小节。跨谱表显示不自动改变逻辑手别。
- 保留原始文件、哈希和版本关系；同一文件重复导入复用原版本，同名文件修改后建立新版本，记录继续关联对应版本。支持导出原谱。

## 新增：认音中的调号记忆

从今日、专项或认音入口进入“认音进阶 · 调号影响”：

1. 先比较同一谱位在零号与新调号下的区别，解释调号为什么影响这个音。
2. 撤去提示，找到实际琴键；随后换音区、换谱号，再混合受影响与不变的音。
3. 区分忘看调号、八度错误等情况；首次输入前不计时，按键后 1 秒无新输入自动确认。
4. 提示、听示范和短时曝光记为辅助，独立正确与辅助正确分开保存；错误题 1 分钟后可短时回测，正确题 11 分钟后安排复习。

当前课程覆盖零号及 ±1～±3 个升降号；调号影响相同字母的所有八度。连接实体 MIDI 琴与屏幕琴键均复用原 APP 的输入和声音，切页、打开 MIDI 面板或进入后台会撤销待判计时并清音。

## 备份与升级

- **曲库 → 备份曲谱库**：新增 v3 ZIP，包含原文件、曲谱版本、练习记录和设置；用“导入曲谱”选择 ZIP 恢复。继续接受旧版 v1/v2 JSON 曲库。
- **薄弱音/档案 → 导出数据**：主学习 JSON 包含认音、课程、乐理与调号记录。它与曲库 ZIP 分开保存，升级前建议两份都导出。
- 与 1.6.0 使用相同包名、相同签名，版本 code 从 17 升为 18，可覆盖安装；不要先卸载旧版。旧数据原地迁移，导入旧主备份会保留现有调号记录。新版主备份为 v7，旧版 APP 不保证能读取。

## 当前限制

- 直接导入目前验证了 MSCX 3.02 / 4.70 的若干真实样本和固定复杂样本，不代表兼容这两个版本的全部记谱写法。未知或未支持内容会拒绝转换或给出定位提示。
- 一种和弦括号 `ChordBracket` 尚未绘制；装饰音显示，但不纳入播放和认音目标。
- 非连续延音片段保留源关系，暂不开放播放和跟拍考核，认音可继续；部分旧 3.02 八度线区间存在记谱/实音兼容差异，禁止该区播放、判分和不可靠键位提示。
- 表情文字保留，但表现性力度、延长及松键评价尚未完整还原。文件导入和原谱/ZIP 导出预算为 5MB，复杂谱面可能短暂阻塞。
- 已完成浏览器实际点击、模拟原生 MIDI、存储/备份、Java 构建、同证书和 APK 解包核验；真实安卓平板 USB、系统文件选择器落盘与密度体验仍待实机测试。一个依赖旧隐藏控件的历史 MIDI UI 脚本未完整跑通，新生产界面的路由和生命周期另有回归验证。

本次公开的是此前已验收的同一测试 APK，没有重新构建；包内个别文字仍显示“本地测试未发布”，该文字描述的是构建时状态。
