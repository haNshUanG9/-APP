# 1.5.8 平板适配版

本版针对平板窗口适配、操作路径和对齐问题进行调整，保留简约谱台和黑色音符。

- **首页按窗口自然排布**：窄窗与短高窗口允许内容自然长高，避免训练入口与练曲入口挤在一起。
- **专项页不再互相遮挡**：较宽窗口使用列表与参数两区；竖屏、分屏等较窄窗口改用单列自然滚动，参数区排在列表之后。
- **完成操作固定可见**：本轮模式、速度、片段设置使用固定标题和底部操作区，正文内部滚动；短高窗口不必滚到底才能返回谱面。
- **曲名直接打开曲库**：曲库、学习路线与高级设置分开显示，选择曲目后直接回到谱面；练习进行中保持条件锁定，面板提供结束本轮入口。
- **对齐与触控统一**：页头、反馈栏和琴键共用工作区边距；主要通用控件的网页命中区至少 48×48 CSS px，保留简洁外观。实际 dp 与手感仍需设备验证。
- **更清楚的导航**：专项菜单使用菜单图标；退出专注使用关闭图标；返回按钮继续承担返回上一层的作用。
- **琴键保留可弹宽度**：局部琴键提高最小键宽，较宽音域通过横向滚动查看；收起琴键保留当前题目并扩大谱面。
- **谱面按内容窗口排版**：每行小节数和完整谱行数量按可用宽高调整，收起琴键和专注切换重新排谱，音符保持黑色。
- **节奏设置减少嵌套滚动**：准备练习入口独立于正文滚动；窄窗课程入口横向分组，节拍器提供明确的关闭操作。
- **安卓可用区域适配**：宿主依据系统边缘、手势、屏幕缺口和输入法占用区调整网页实际可用窗口。

数据与安装：继续使用原应用包名和签名，versionCode 从 14 升至 15，可覆盖升级。练习数据结构保持兼容。

验证：核心与课程检查、生产 HTML 多窗口截图、关键按钮命中与状态保持检查、APK 签名与资源一致性校验。当前没有真实安卓平板和 USB MIDI 硬件，系统边缘、输入法及设备连接的最终手感仍需真机确认。
