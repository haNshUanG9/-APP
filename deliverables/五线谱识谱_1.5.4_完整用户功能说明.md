**五线谱识谱 1.5.4｜完整用户功能说明**

适用版本：钢琴采样版 1.5.4，Android 10 及以上。本文说明当前安装版已经提供的功能；参考网页中的新设计另列在文末。

**一、这款应用可以帮你练什么**

应用围绕“看懂谱面、找到琴键、按拍弹出、反复巩固”安排练习。适合刚开始认识五线谱，或希望加强音高定位、读谱与基础节奏的用户。

你可以从循序课程开始，也可以单独练容易混淆的音、加线音、短句和节奏；有自己的曲谱时，可以导入后试听、分段认音、跟拍或考核。

| 想解决的问题 | 建议使用的功能 |
| --- | --- |
| 完全不知道从哪里开始 | 今日练习 → 继续循序学习 |
| 某几个音总是认错 | 专项练习，或进步记录中的薄弱音练习 |
| 单音认得出，连起来就慢 | 短句读谱 |
| 音高大多正确，但节拍不稳 | 节奏与拍子，或曲谱跟拍练习 |
| 想练自己喜欢的曲子 | 我的曲谱 → 导入曲谱 |
| 想知道过几天是否还记得 | 到期复习与曲谱回测 |
| 只想给练琴打拍子 | 独立节拍器 |

应用可以离线使用，无需注册账号。练习内容、内置钢琴采样与记录保存在设备本机。

**二、第一次使用与主要入口**

安装 APK 后打开应用。完全零基础建议从首页的“继续循序学习”开始；已有基础可以打开课程地图，试听并选择合适的起点。没有实体琴时，可以先用屏幕琴键操作。

顶部菜单按需展开，主要提供五个入口：

| 入口 | 可以做什么 |
| --- | --- |
| 今日练习 | 继续当前课程、开始到期复习、进入专项或节奏训练 |
| 专项练习 | 参照音、易混音、加线音、反向定位及节奏训练 |
| 短句读谱 | 将单音连成短句，进行学习、连续跟拍或测评 |
| 我的曲谱 | 使用内置曲谱，导入自己的曲谱，试听、分段练习与考核 |
| 进步记录 | 查看练习报告、薄弱音、错题、复习安排及数据备份 |

顶部输入状态按钮用于打开实体琴连接与输入设置。“收起键盘／显示键盘”用于调整训练工作区；曲谱页也有独立的屏幕琴键开关。收起键盘会扩大谱面，不会重置当前题目。

打开菜单或输入设置会暂停正在进行的训练。返回训练后，请按页面提示继续。

**三、连接实体钢琴或 MIDI 键盘**

连接顺序为：琴的 **USB TO HOST → 支持数据传输的 USB 线／转接头 → 安卓平板**。平板和转接设备需要支持 USB 主机功能，琴需要提供兼容的 USB MIDI 输出。

连接后，点击顶部输入状态，打开“实体琴与输入”：

1. 查看应用是否发现设备；没有发现时点击“刷新设备”。
2. 有多个设备或端口时，选择要使用的一项，点击“连接所选设备”。
3. 在琴上弹一个音，检查面板是否显示收到的音名和力度。
4. 选择自动输入、实体琴或触屏输入，再返回练习。

连接面板还可以设置接收通道、谱面大小、自动继续和屏幕按键监视。默认接收全部通道；确实需要限制输入来源时再选择具体通道。

认音题会检查具体音高与八度。中央 C 统一记作 **C4**，C3、C4、C5 分别是不同位置的音，不能互相替代。

节奏训练使用指定作答键：默认左侧 C3、右侧 C4，单侧课程使用右侧键。点击面板中的对应设置，再弹一个琴键即可更换。这里检查节奏，不要求按出旋律音高。琴键到谱面的反向定位仍通过点击谱面作答。

实体琴按键使用琴自身的声音；应用负责课程示范和节拍器。面板可显示踏板状态，但时值训练按实际松键计算。断线、切换输入或进入后台会暂停相关训练。

独立 HTML 文件可用鼠标或触屏试练；当前 USB MIDI 连接通过安卓安装版使用。

**四、循序入门：6 章、18 课**

课程从少量音开始，每次集中加入一个主要难点，再把它放进短乐句。

| 章节 | 课程内容 |
| --- | --- |
| 第 1 章：三个音，先认准 | 第 1—3 课：G4 参照、加入 F4、加入 A4 |
| 第 2 章：长短与留白 | 第 4—5 课：二分音符、四分休止 |
| 第 3 章：走向中央 C | 第 6—9 课：E4、D4、C4，以及 C4—A4 的连接 |
| 第 4 章：向高音延伸 | 第 10—12 课：B4、C5，以及成对八分音符 |
| 第 5 章：换到低音谱表 | 第 13—16 课：F3 参照，加入 E3、G3、C3 |
| 第 6 章：把它连成音乐 | 第 17—18 课：高低谱表轮换、四小节综合应用 |

课程配有 36 条编排乐句，每课有原句和变化检查乐句。学习过程依次连接认识内容、独立认音、有参照听辨、听后跟弹、读准原句、同句慢速跟拍和变化检查。

听辨需要先听完示范，再判断音的关系；跟弹需要先听音组，再按顺序弹出。原句读准可以慢慢纠错，进入跟拍后则按拍点连续完成。课程跟拍速度可选 40、50、60、70、80 BPM。

用提示完成、错后纠正和中断轮次分别保留记录，不能直接替代独立通过。未通过时继续当前阶段，避免在还没认稳时不断加入新内容。

课程地图允许选择起点和预习，跳课不会自动把前面的课程标为掌握。课程阶段和待回测任务保存在本机。高低谱表轮换课一次只弹一个音，不等同于双手同时演奏。

**五、专项练习：集中解决一种困难**

| 专项 | 练习方法与目的 |
| --- | --- |
| 参照音定位 | 从熟悉的参照线、参照音出发，认识周围位置 |
| 易混音对照 | 成对比较相邻音、跳进或不同八度，结合实际错键记录巩固 |
| 加线音专项 | 从靠近谱表的加线逐步向外扩展 |
| 琴键到谱面 | 先看高亮琴键，再在指定谱表的候选音中找到它 |
| 到期复习 | 检查之前练过、现在已经到期的音 |

专项提供两种安排。“循序课程”使用明确的小音组，重复巩固后推进；“自由抽题”允许按音域和难度混合练习。

可选择高音、低音或高低混合谱表，每轮 10、20、40 或 60 题。自由抽题提供入门、基础、拓展三档音域；循序课程按当前单元安排音组。

循序路线会穿插旧内容，并把弹错或用过提示的目标放入隔题回测。短轮可以跨轮积累有效表现，一轮结束不代表整个单元已经完成。

在音高专项的学习作答中，当前组全部答对并松键后，等待 **1 秒无新输入**便自动继续，最后一组自动显示结果。期间再弹会重新等待；新题出现时不开始计时。错音、未完成的一组或持续持键均不会触发自动换题。页面仍保留“立即继续”；实体琴用户也可在输入设置中关闭自动继续。

**六、自由识谱：自己决定音域与题量**

从首页进入自由练习，可按自己的目标调整：

| 设置 | 可选内容 |
| --- | --- |
| 谱表 | 高音、低音、高低混合、双谱表 |
| 音域 | 入门、基础、扩展 |
| 每题音数 | 1—15 个，双谱表至少 2 个 |
| 每轮题量 | 10、20、30 题 |
| 出题方式 | 自动加练、均衡覆盖、自己选音、薄弱音专项 |
| 计时 | 按音数计算、自定义整题时限、不限时 |
| 键盘 | 局部键盘或完整 88 键 |

自动计时可按每音 3、5、8、10、15 秒分配整题时间，自定义时限为 3—900 秒。同一题的所有音共享总时间。

多音题按谱面编号依次作答；双谱表同一列先上方、后下方，再进入下一列。选错可以改正，但纠正完成不会算作首次正确。超时只记录已经轮到的音，尚未轮到的音不计错。

“自动加练”增加易错和找键较慢的音，同时继续覆盖其他位置。“自己选音”用于固定练几个音；混合和双谱表需要在高、低谱表各选至少一个音。“薄弱音专项”使用已有薄弱记录，没有合适记录时会提示。

屏幕琴键在一轮内保持音域稳定，可横向滚动；88 键覆盖 A0—C8。基础自由识谱题以自然音为主，黑键也可按下发声。

同一题中认对后进入下一个音，整题完成后显示结果。实体琴自由识谱可设置松键后的自动换题停留为 0.35、0.65 或 1.2 秒；它与专项固定的 1 秒静候规则分别设置。

**七、短句读谱：从认单音到连续读音乐**

短句读谱提供循序课程和自由短句。

循序课程围绕已练过的音组保留同一句：先读准，再收起提示独立完成，再按较慢速度跟拍，最后用小变体检查。尚未取得所需认音证据时，页面会提示先补相应音高练习。

自由短句可设置 1—15 个音，选择高音、低音、混合或双谱表，以及级进、重复、三度和混合音型。双谱表可练上下交替、低音长音配高音移动、上下同时起音。短句以自然音、4/4 拍为基础。

| 训练方式 | 作答规则 |
| --- | --- |
| 学习 | 可以停下来纠错、查看提示；完成当前组后按静候规则继续 |
| 连续 | 预备拍后跟着时间连续弹，休止处等待，结束后复盘 |
| 测评 | 使用新短句，关闭音高提示，检查独立完成情况 |

短句主要检查音高与起拍。需要专门练按住多久、何时松开时，请进入节奏训练。

**八、节奏训练：六类练习**

从专项练习进入“节奏与拍子”，或使用首页的节奏入口。

| 课程 | 怎样作答 |
| --- | --- |
| 稳拍训练 | 每拍一次，可设置后半段节拍器静音，检查能否继续保持速度 |
| 八分细分 | 一拍分成两个等长起点，配合“1 & 2 &”数拍 |
| 时值与休止 | 按下表示开始，按住表示延续，松开表示结束；休止处不按 |
| 节奏型专项 | 按谱面完成节奏型，分清起点、长短与留白 |
| 听后模仿 | 先听完示范，再复现节奏；作答时隐藏谱面，结束后对照 |
| 双手节奏 | 使用两个输入区或指定琴键，练两条声部的时间配合 |

拍号支持 2/4、3/4、4/4，四分音符为一拍。训练速度可设 **30—240 BPM**。自由练习可选每段 1、2、4 小节，内容由四分、二分与休止逐步加入八分、半拍休止和附点节奏。

循序课程按稳定四分起点、四分与二分、小节末等待、中间休止、八分细分、半拍休止、附点与八分推进。每个母型经历固定重复、取消数拍、混入已学节奏和交替检查；课程会安排当前阶段的小节长度与提示条件。

先点“准备练习”，按需听示范、看节奏拆解，再点“开始练习”。听后模仿须先听完示范。预备拍长度随拍号变化：2/4 为 2 拍、3/4 为 3 拍、4/4 为 4 拍。

触屏使用大输入区，双侧课程可以同时操作两个区域。电脑试用时，单侧可用空格，双侧可用 F、J；时值课程需要保持按住并及时松开。实体琴使用连接面板指定的节奏键。

结果分别列出拍点命中、起拍偏移、时值、漏按和多按，并提供示范、实际按键回放及针对练习。偏移为负表示偏早，为正表示偏晚。起拍正确与时值正确分别判断。

时值练习采用“按住表示延续”的教学规则，不用来统一评价钢琴连奏、断奏或踏板处理。双侧输入也不能证明实际用了哪只手。

**九、独立节拍器与偏移校准**

在节奏准备页展开“独立节拍器”，无需生成题目即可使用。

- 速度：30—240 BPM，可输入、拖动滑杆或用加减按钮调整。
- 拍号：2/4、3/4、4/4。
- 细分：每拍 1、2 或 4 响。
- 可设置第一拍重音，查看当前拍指示。
- “跟拍设速”根据连续点击估计速度。
- “应用到训练”把选好的节拍器速度与拍号用于训练设置。

节奏辅助设置提供 −250 至 +250 ms 的偏移调整，也可以“听 8 拍并校准”。正偏移会从输入时间中扣除。校准参考包含你的跟拍反应，适合辅助调整，不能精确测出设备硬件延迟。

**十、我的曲谱：内置材料与文件导入**

打开“我的曲谱”，通过“曲目与设置”管理曲库、选择内容和调整练习条件。

当前内置 8 首原创练习：

| 曲目 | 长度 | 主要练习内容 |
| --- | --- | --- |
| 第一段音乐 | 4 小节 | 右手逐拍与左手长音 |
| 纸上小路 | 4 小节 | 单手自然音连接 |
| 晚风问答 | 8 小节 | 句尾等待与前后句连接 |
| 低音回声 | 8 小节 | 低音定位与句子连接 |
| 双手小舟 | 8 小节 | 旋律与低音长音配合 |
| 半拍微风 | 16 小节 | 成对八分与更长片段连接 |
| 窗边新色 | 16 小节 | 在熟悉音域中加入 F♯ |
| 和音灯火 | 8 小节 | 二音和声位置与起音 |

内置材料注明学习目标和先修要求，可以预习，但不会因此把先修内容标为掌握。

导入自己的曲谱时，点击“导入曲谱”，通过系统文件选择器选择文件。支持 `.mid`、`.midi`、`.musicxml`、`.xml`、`.mxl`，也可在此恢复应用导出的曲谱库 JSON。

MIDI 导入后会整理成五线谱，可以选择十六分、八分或三连音网格，并调整左右手分界。整理设置不修改原 MIDI 文件。MIDI 没有完整的记谱信息，复杂多声部建议先用 MuseScore 整理，再导出 MusicXML。MusicXML 更适合保留原谱排版信息；反复与跳转请先在制谱软件中展开。

普通曲谱单文件上限 5MB，最多 20000 个音、2000 小节；MXL 解压后上限 25MB。当前不直接导入 PDF、照片或录音成谱。

**十一、曲谱的四种使用模式**

| 模式 | 功能与判定 |
| --- | --- |
| 认音练习 | 看谱找到目标音，同组音弹齐并松键后继续；允许慢慢找齐和弦，可使用分层提示 |
| 跟拍练习 | 预备拍后连续演奏，检查音高与起拍，分别统计漏音、多按和偏移 |
| 考核 | 选择仅认音或音高加节奏，关闭提示，固定当前声部、片段、速度与输入条件 |
| 欣赏 | 使用本机合成琴音播放选段，光标跟随谱面，可设置循环与速度 |

练习前可选择声部、右手／高音谱表、左手／低音谱表或双手，填写起止小节，设置 **20—240 BPM** 的速度及谱面大小。跟拍模式可选择播放另一声部伴奏。高级设置提供节拍器、选段循环、起拍容差与输入偏移。

点击“开始”进入练习，使用“暂停／继续”和“结束”控制本轮。“整曲”可把范围恢复为全曲。曲谱页的屏幕琴键可以收起，连接实体琴后主要在琴上作答。

当前版本的范围和速度在练习前设置，开始后锁定；需要更改时先结束本轮。打开曲库或设置不会丢失当前谱面滚动位置，练习中打开会先暂停。

曲谱认音的松键继续与专项的 1 秒静候属于不同流程。认音模式允许逐个找齐和弦，完成它不表示已经掌握同时起音；这需要在跟拍中另行检查。

曲谱模式评价音高与起拍，不统一要求所有音按满谱面长度。考核成绩是本应用练习规则下的结果，不是钢琴等级证书或标准化考试成绩。

**十二、分段学习、困难拆练与回到原句**

在曲谱设置中选择“按全曲分段学习”，应用会以两小节为基本单位，再逐步连接四、八、十六小节等更长片段。

有双手目标时，路线安排“听清这一段 → 右手读准 → 左手读准 → 整段独立认准 → 原句慢速跟拍 → 目标速度检查”。只有单手内容时跳过不适用的分手阶段。慢速与目标速度阶段各需两次完整独立完成。

自动分段按小节长度安排，不代表自动理解了音乐乐句。你也可以退出引导，自行选择范围。切换目标速度、声部或输入条件会分别记录相应进度。

每轮报告会列出具体问题位置。红色标记错音或漏音，金色标记提示目标或起拍问题，点击报告中的位置可回到谱面。

按“主要困难拆练”后，应用根据当前表现选择练习：音高、八度容易错时先不限时认准；音高较稳而起拍不稳时练原小节节奏。完成后使用“回到原片段检查”，确认拆练是否帮助了原曲。

报告还可试听标准片段和本次按键。本次回放保留实际停顿及按下、松开长度，每次最多两分钟；回放本身不生成新的练习成绩。

**十三、记忆提示：需要时展开，熟悉后独立检查**

在识谱、音高专项、反向定位和短句学习中，可以打开“帮助我记住”；曲谱认音中可使用“给我提示”。

| 层级 | 提供的帮助 |
| --- | --- |
| 第一层：参照 | 提醒谱表、音区与附近参照音 |
| 第二层：关系 | 展示上行、下行、线间移动，以及适用的升降记号关系 |
| 第三层：答案 | 展示目标音名、谱面位置与对应键位 |

基础练习的谱面提示可以标出参照线、参照音和移动关系；曲谱提示根据当前未完成目标提供帮助，部分内容可试听参照与目标。

看过提示的音单独记录。收起提示不会把本次作答改成独立认准；之后仍需要无提示检查。自由识谱打开帮助时，本题转为不限时，提示样本不用于识别速度统计。

连续短句遇到困难时，可转入同一句的辅助学习，再返回原训练无提示检查。节奏拆解可在准备或练后查看，正式跟拍时收起；使用过拆解的轮次作为辅助练习，不直接推进独立通过。

**十四、练习记录、薄弱项与到期复习**

进步记录汇总专项、短句和节奏报告，也提供自由练习的薄弱音、错题本和历史入口。曲谱历史与分段学习状态可在曲谱工作区查看，曲谱回测也有首页和进步页入口。

阅读报告时，建议同时看准确率、样本数、提示使用和漏按多按：

- **首次正确**：第一次作答就认准；先错后改不计入首次正确。
- **辅助完成**：借助提示完成，或仍有需要纠正的问题。
- **找键用时**：包含看谱、找键和输入操作，不等于纯粹的识谱反应速度。
- **起拍偏移**：已匹配输入相对目标的提前或延后；漏按、多按需要另外看。
- **独立完成／重复完成／回测保持**：分别说明当前练习与后续检查取得的证据。

高音、低音、具体八度，以及触屏和实体琴的表现分别记录。不同速度、提示或输入条件下的结果，适合分别观察。样本很少时，先继续积累，不宜只凭一轮百分比判断掌握程度。

薄弱音页可以查看每个音的记录，点击“练这个音”进行定点练习。自由练习错题本可集中复习，也支持手工标记；手工标记是整理工具，不代表课程自动通过。

基础音高复习按有效表现建立计划，错误或提示依赖通常安排约 10 分钟后再查；到期后需两次无提示确认，再逐步延长到 1、3、7、14 天。普通重复答对不会不断推迟到期时间。

曲谱也按片段和练习条件安排回测，首次通常约 10 分钟后检查，完成相应独立确认后逐步延长间隔。复习以本机时间计算，进入应用后查看到期入口。这些间隔是应用的练习安排，不保证适合所有人的记忆速度。

**十五、暂停、界面与声音**

应用以平板看谱为主要场景，支持横竖屏，菜单和曲库设置按需展开。训练谱面随可用空间排版，曲谱也提供大小设置。屏幕键盘收起后，当前题目、提示记录与暂停状态保留。

需要中途离开时使用“暂停”，回来后点击“继续”。切换页面、打开相关设置、进入后台或实体琴断线，也可能暂停当前训练。暂停轮次会保留已产生的记录，但不会冒充一次完整独立通过；时值训练中被中断的长音会按中断处理。

识谱试听、课程示范、曲谱欣赏、伴奏与回放使用内置 Salamander 钢琴采样；节拍器和节奏提示使用本地短音。没有声音时，先检查设备媒体音量，点击播放或示范启动音频，并检查相关声音设置。实体琴自身的发声由琴控制。

**十六、保存、备份与升级**

学习进度、薄弱音、报告和曲谱均保存在本机。卸载应用、清除应用数据或设备损坏可能造成丢失，建议定期导出备份。

当前有两类备份，分别导出和恢复：

| 备份 | 操作入口与内容 |
| --- | --- |
| 课程与练习数据 | 进步记录 → 薄弱音与数据备份 → 导出数据；包含课程、音符档案、专项、短句、节奏及相关复习记录 |
| 曲谱库数据 | 我的曲谱 → 曲目与设置 → 备份曲谱库；包含曲谱、曲谱报告、分段计划和记忆记录；通过“导入曲谱”恢复 |

导入课程与练习备份会替换相应的当前数据，建议先导出已有内容。课程数据备份使用应用导出的 5MB 以内 JSON；有活动训练时，先结束再导入。两类备份不能互相替代。

1.5.4 支持覆盖安装同签名的 1.5.0，无需先卸载；升级前建议把两类备份都保存到应用以外的位置。旧版曲谱库备份仍可恢复。不同 HTML 文件与 APK 不保证共享存储，需要通过备份迁移。

**十七、推荐怎样安排一次练习**

零基础用户可以先完成一段当前课程，再检查少量到期音；遇到反复认错的音，进入对应专项。单音逐渐稳定后，用短句把它们连起来。

练自己的曲谱时，先选一两小节试听，再分别认准，之后慢速跟拍。练后先解决报告指出的主要困难，回到原片段检查，逐步连接前后内容。过一段时间再独立回测。

发现节拍不稳时，可以减少音高任务，单练稳拍或原片段节奏；认音仍不稳时，则先降低连续演奏压力。提示用于帮助理解，熟悉后再收起检查。

**十八、当前范围与后续功能**

当前通过屏幕操作或 MIDI 检查按键音高、起拍，以及专门节奏课程中的按住时值。应用无法判断实际使用的手、手指、手型、踏板技巧、力度处理或艺术表达，也不通过麦克风识别钢琴声音。屏幕上的左右手选择是练习目标设置，不能证明演奏者实际用了哪只手。

MIDI 左右手由分界音推定，复杂交叉手内容需要人工整理；导入谱面也可能需要在制谱软件中校对。内置练习用于基础应用，不能替代完整教材与教师指导。

刚讨论的左右手彩色联动提示、指法预览、可拖动小节导航、谱面直接点选 A-B，以及演奏中直接调速，尚未包含在本版。当前已有小节范围设置、选段循环、练前变速和谱面光标。

本版已完成构建和桌面浏览器功能检查，尚未连接真实安卓平板与实体琴验证；不同设备的 USB 兼容性、音频和触控延迟需以实际使用为准。
