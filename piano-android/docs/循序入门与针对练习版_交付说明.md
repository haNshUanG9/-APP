# 循序入门与针对练习版

日期：2026-10-30

本次落实方案中的 1、2、4：修正课程覆盖与进度，建立三个音的入门单元，并根据当前困难启动下一项练习。交付文件为 `deliverables/五线谱识谱_循序入门与针对练习版.html`。

## 如何体验

用 Chrome 或 Edge 打开 HTML，首页选择“开始 / 继续入门”。声音由本机合成，首次点击播放后启用；无需网络或额外音源文件。

1. 按 G4 → F4 → A4 推进，每次只加入一个新音。
2. 先听示范、看谱位与键位，再独立认音，之后进行有参照的听辨和短音组跟弹。
3. 认音提示依次给出 G4 参照线、相邻线间关系、目标音名与位置。用过提示、答错后纠正、或中断后完成，都不计作独立掌握。
4. 提示题和错题在两道穿插练习后收起帮助回测。穿插练习不代替本阶段的独立证据，也不会不断增加回测队列。
5. 第一个音至少六次独立认出，后续新音各至少四次；每小课另外完成四项听辨和四项完整跟弹。听辨按固定比较顺序覆盖同音和高低方向；跟弹使用固定音组连接新旧音。缩短为单音只作辅助，随后回到完整音组。
6. 完成后可反复回顾，并进入固定两小节：`G4 F4 G4 F4 | G4 A4 F4 G4`。先不限时读准，保留原有短句与节奏练习入口。

入门认音会进入原有本机认音记录和到期复习安排；听辨、跟弹分别统计。触屏与 MIDI 的证据各自保存。“本次通过”仅代表本次完成，后续仍需到期回测。

## 节奏课程修正

每个母型按“固定重复 → 收起数拍 → 混入已学节奏 → 交替巩固检查”推进，再进入下一个母型。已去除重复或错分类的条目，并补回全音符母型。八分课先出现一组八分，随后增加数量。

课程位置按模式、拍号、输入方式保存。改变速度、节拍器等条件会分别记录表现证据，课程位置仍保留。失败保留当前题；旧进度兼容迁移。

## 复盘建议

专项和短句报告会说明当前证据支持的主要困难，并提供直接开始的按钮：

- 整八度错键：固定出错音练键位。
- 音高混淆或提示依赖：限定一至三个问题音，不限时练十题。
- 音高较稳、拍子不稳：提取出错小节，降速单练节奏。
- 漏按较多：缩短到具体小节，先读准再回原句。
- 原句稳定：在已出现的音中只改一个音检查；没有合适变化时保持原句再确认。

不足四个已评估音、偶发错误、或曾中断的报告会保留“不足以判断”的解释。专项继续练习沿用原任务与范围；短句重练保留具体谱面。由原句提取的节奏报告会保存对应原句，刷新后仍能返回。

## 本机数据和实体琴

新版保留原有数据格式和 JSON 备份入口。更新到另一个 HTML 文件时，建议从旧版导出备份，再在新版“薄弱音与数据备份”中导入；浏览器不保证不同文件共享存储。不要用覆盖浏览器数据的方式迁移。

这次提供 HTML，支持离线触屏练习和试听。USB MIDI 仍使用项目已有的 Android 原生通道，未新增浏览器 Web MIDI。新入门单元已接入原生输入路由，包含八度判错、松键后换题、断线暂停和输入隔离；已完成模拟输入测试，尚未用实际平板和实体琴验证。本次没有重新生成 APK。
