## 1.4.0 循序课程与重复巩固

专项默认进入循序课程，保留自由抽题供已熟悉内容的混合练习。课程按任务、谱表和输入方式分别记录，旧版记录保留，但不会据此自动判定课程通过。

- 每个音高单元含1～3个明确目标。高音参照路线从G4开始，再加入F4、A4，随后学习中央C与其他参照位置。低音、易混音、加线音和反向定位各有明确的小单元顺序。
- 初次接触音高目标时显示音名和位置，计作提示，不计入无提示掌握；随后用固定小音组反复作答。新单元后半段每五题保留一题旧内容。
- 弹错、用提示或暂停的目标进入回测队列：隔两道其他作答检查，第一次回测正确后再隔六道作答检查。每轮最多12道加练；超过上限或不足间隔的回测保留到下一轮，不以紧接着答对冒充完成间隔确认。
- 当前目标各至少4次独立无提示正确；多目标需要隔题证据，单目标至少6次；错误的重点和旧内容都不能带着未完成回测通过。10题短轮可以跨轮积累证据。退出或重启后恢复计划、位置和待回测任务。
- 短句课程从已取得4次无提示音高正确的目标构建固定6音句。先认准原句，再同句无提示，再同句50 BPM跟拍，最后用只改变一个位置的小变体检查。未通过保留原句，暂停轮次不升级。
- 节奏课程每段固定4小节，先同型连续重复，再取消数拍，再混入旧节奏，最后检查小变体。完整、无漏按多按、起拍偏差不超过一拍18%、时值符合原规则且未暂停时推进。七个内容单元为四分起点、四分与二分、小节末等待、中间休止、八分细分、半拍休止、附点与八分。
- 自由节奏模板升级时完整保留前一档再加入新模板；自由模式和课程模式可切换。结果页优先重练同题，另提供自由新题。
- 长期复习按任务（看谱弹琴 / 谱面定位 / 短句）和输入方式分别保存。至少4次无提示正确才建立初始1天复习；错误与提示依赖安排10分钟后检查。普通正确不升级、不取消错误后回测、不推迟到期时间。
- 到期复习需要两次无提示确认后才延长至1、3、7、14天。单个待复习目标插入3道练习形成间隔；短句音高在固定短句中确认。错误复习重新安排10分钟后检查。
- 连续短句漏音更新音符学习档案。看谱弹琴的错误不会被反向定位正确清除；提示依赖进入薄弱项。切换实体琴 / 触屏时保存当前轮次，避免混合输入证据。

上述次数、间隔和阈值为本应用的初始训练规则，后续可依据实际使用调整；单元通过与长期记忆掌握分别判断。

## 节奏与拍子

从「专项练习 → 节奏与拍子」或今日练习的「练节奏」进入。

| 课程 | 作答方法 | 目的 |
|---|---|---|
| 稳拍训练 | 每拍点击一次；可让后半段节拍器静音 | 保持稳定速度 |
| 八分细分 | 一拍点击两个等长八分起点 | 理解数字与 & 的半拍位置 |
| 时值与休止 | 音符处按下，按住延续，松开结束，休止处不按 | 分开练起拍、持续与松键 |
| 节奏型专项 | 按谱面起点点击，休止处不按 | 识别并完成一组节奏 |
| 听后模仿 | 先听示范；练习时隐藏谱面，结束后对照 | 连接听觉与谱面 |
| 双手节奏 | 左侧保持长音，右侧完成节奏；支持同时按住 | 练两条声部的时间配合 |

拍号支持2/4、3/4、4/4；四分音符为一拍。速度为40—120 BPM，步长5；每段1、2或4小节。预备拍数随拍号变化，2/4预备2拍，3/4预备3拍，4/4预备4拍。

基础包含四分、二分、全音符与休止；进阶加入八分和半拍休止；第三档加入附点四分（1.5拍）。每条声部都按完整小节生成。稳拍固定四分起点，八分细分固定半拍起点。

先点「准备练习」，可听示范，再点「开始练习」。听后模仿需要先听完示范；其他课程可自行选择。数拍可以关闭；课程参数和提示条件在开始后保持固定。

时值练习采用“按住表示延续”的教学规则，不作为钢琴连奏、断奏或踏板演奏的通用判定。双侧输入检查声部与时间，不能验证你实际用了哪只手，也不检验真实钢琴指法。

触屏可同时按两个输入区。电脑辅助操作：单侧课程用空格，双侧用 F 和 J；时值课程保持按住，松开结束。

## 节奏评分和加练

起点按同声部、最近时间窗口匹配。窗口不超过一拍的32%，也不超过相邻同声部起点间距的42%。命中率表示匹配到起点的比例，命中后仍单独显示偏早、偏晚。

时值按实际按住时长与谱面时值比较，显示提前松开或延续过长。容差由速度与音长计算，并保留初学者操作余量；规则是本应用的初始训练参数，没有作为标准化音乐考试评分。

报告分别列出起点命中、起拍偏移中位数、时值正确、漏按、多按、休止处多按和中断排除。偏移负值表示偏早，正值表示偏晚。偏移、波动和趋势只使用匹配到的样本；窗口之外的按键会形成漏按与多按，不能仅凭匹配样本推断全部错误原因。

报告提供标准示范、实际按键回放、标准与实际时间对照，以及“练这一项”的入口。时值课程回放包含实际按住时长；点击课程回放只表达起点。报告保留最近60轮，可在进步记录中重新打开。

节奏薄弱档案与音高档案分开。节奏型按课程、拍号、内容、速度、数拍提示、节拍器状态和偏移设置分别累计；至少3个同条件小节样本后，近期不稳定的节奏型才增加抽样权重，同时继续覆盖其他节奏型。当前加练参数是可调整的初始规则。

暂停、离开页面或进入后台会停止计时。暂停所在长音和系统取消的触点标为中断，排除对应评分；曾暂停的轮次保留报告，不更新节奏薄弱档案。中途结束只统计已经发生的拍点，后续拍点不计错；未完成的小节不更新节奏型档案。

## 节拍偏移校准

在课程设置中展开「节拍偏移校准」，可手动设置−250至250 ms，或听8拍并跟拍，参考至少5个有效点击的中位偏移。正值会从作答时间中扣除。这个参考包含你的跟拍反应，不能精确测出硬件音频或触屏延迟；可再手动调整。

## 识谱和短句继续保留

参照音定位、易混音对照、加线音、琴键到谱面的反向定位，以及到期复习继续可用。高音、低音、混合和双谱表分别按具体音高与八度记录。中央C记为C4；不同八度不能算成同一个音。

自由识谱每题默认1音，最多15音；支持自动加练、均衡覆盖、自己选音与薄弱音专项，以及共享整题倒计时。正确后进入下一个音，错误可以改正；超时只记录当前已轮到的音，后续音不计错。双谱表自由识谱仍按编号顺序作答。

短句包含1—15音、级进、重复、三度和混合音型，以及上下交替、低音长音配高音、上下同时起音。题目采用自然音和4/4拍。学习模式可纠错，连续模式按拍点前进，测评关闭音高提示。短句仍评估音高与起点；持续按住的时值评分请使用节奏课程。

键盘支持局部和完整88键。黑白键都可发声，当前音高题考自然音。题目音域在一轮内固定。对易错音和较慢找键的原有加练继续保留；找键用时包含读谱、找键和触屏操作，不能当作纯识谱反应速度。

专项无提示复习的初始间隔为1、3、7、14天，同日反复答对不会连续升级；错误或用过提示后约10分钟再检查。复习采用本机时间，这些是初始规则，不是经验证的最优学习算法。

## 数据备份

数据格式为V5，兼容导入V2、V3、V4。原音符档案、错题和历史保留；新节奏报告、节奏型档案与校准设置一同导出。JSON通过Android系统文件选择器导入导出，最大5MB；有活动训练时需先结束再导入。

## 开发构建

- web/core.js、web/app.js：原自由识谱及本地数据。
- web/study-core.js、web/study-ui.js：音高专项、短句与复习。
- web/rhythm-core.js：完整小节出题、起点及按住时值评价、节奏型档案。
- web/rhythm-ui.js：课程、触点、节拍器、示范、回放与校准。
- web/workspace.css：紧凑平板工作区；旧样式作为兼容基础。
- native：Android本地WebView外壳、数据保存与系统文件选择器。

音乐字形来自Bravura，许可证在native/assets/Bravura-OFL.txt。Babel仅用于构建，不进入APK，其许可证在web/vendor/BABEL-LICENSE.txt。

Linux x86_64需要Java17、Node.js、Python3、OpenSSL以及Android构建依赖。首次运行prepare_tools.py需联网下载并校验构建工具；之后可离线构建。

```sh
python3 piano-android/prepare_tools.py
python3 piano-android/build_apk.py
```

发布时沿用signing中的原发布密钥和证书，保证可以覆盖升级。源码备份中的私钥只用于你自己的后续签名，不应公开。
