本次针对“上一版太简单”的反馈修改实际课程与界面。交付文件：`deliverables/五线谱识谱_18课音乐入门增强版.html`。保留旧 HTML，便于对照和导出旧数据。

## 找到的问题与改动

| 原来的问题 | 本次处理 |
|---|---|
| 三个音后缺少明确的后续内容 | 扩展为 6 章、18 课，从 G4/F4/A4 到中央 C、高音区、低音谱表与四小节应用 |
| 有重复次数，但应用内容太少 | 编排 36 条乐句，每课有原句与另一条检查乐句；已验证 36 条的音高、时值与休止结构互不重复 |
| 单项答对就结束，难以知道能否读音乐 | 每课形成示范 → 独立认音 → 听辨 → 跟弹 → 原句读准 → 同句跟拍 → 变化检查的学习链 |
| 第一个单音课反复太久 | 单音起步先两次独立认音，应用从一小节进入两小节；混合音组要求各旧音确认、新音四次独立确认 |
| 提示主要是文字 | 直接标出参照线、参照音和线间移动箭头，第三层才显示音名与键位；后续回测收起帮助 |
| 已有基础也需要从头做 | 课程地图允许选择起点与试听，跳课不把前面课程标成掌握 |
| 切换课程容易失去当前进度 | 按课保存阶段、当前题、提示等级和待回测任务；切课与刷新后仍能续练 |
| 接琴后屏幕仍放着大块答题键 | 新课程的实体琴模式收起屏幕答题键，使用谱面和顶部 MIDI 监视反馈 |
| 一次错误容易影响后续判断 | 下一步建议看最近记录，至少重复出现才突出；连续独立完成后撤下旧薄弱建议 |

## 内容顺序

1. 三个音：G4、加入 F4、加入 A4。
2. 长短与留白：二分音符、四分休止；音组保持不变。
3. 中央 C 音区：分别加入 E4、D4、C4，再用 C4—A4 连接四小节。
4. 高音区：分别加入 B4、C5，然后在固定音组中加入成对八分。
5. 低音谱表：F3 参照，分别加入 E3、G3、C3。
6. 应用：高低谱表轮换与四小节练习。轮换一次只弹一个音，不要求双手同时。

谱号、音名、黑键分组、加线、时值和休止均由本地代码绘制，声音本地合成，无外部音源与网络依赖。

每条乐句的每小节都是 4 拍；新音必须在本课音组里，长短、休止和八分分别在专门课程首次出现。预习可以自由选择，推荐学习顺序仍保持每课一个主要难点。

## 使用

用 Chrome 或 Edge 打开新 HTML，在首页选择“课程地图 / 继续”。左侧按章选课，右侧看教学目标、谱面和试听，选择“继续当前课”或“从这课开始”。竖屏会优先显示选中课程的内容。

听辨先听完再作答，跟弹先听完音组再按顺序作答。提示、错后纠正、中断题与缩短为单音均不记作独立通过；两道穿插练习后再回测。

“原句读准”可以不限时操作并使用提示；有提示的轮次用于学习，收起帮助独立完成后才进入跟拍。原句跟拍与变化检查要求完整、无提示、无错音、无漏按多按、未暂停，并检查起点偏差。失败保留本阶段。速度可选 40、50、60、70、80 BPM，不增加新音来掩盖起拍问题。

跟拍阈值是本应用的初始练习规则，不是标准化考试。此阶段评音高与起点；持续按住、松键和休止的专门练习仍在原有节奏页面。

HTML 使用鼠标或触屏试练。USB MIDI 继续使用项目的 Android 原生通道，本次没有新增 Web MIDI，也没有重新生成 APK。软件路由已通过模拟测试；实际平板、实体琴与延迟仍需设备验证。
