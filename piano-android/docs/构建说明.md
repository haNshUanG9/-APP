# 开发与构建

源码位于 `piano-android/`；`web/` 为离线界面、训练规则和音频模块，`native/` 为 Android 宿主与 USB MIDI 通道。

需要 Python 3、Node.js、Java 17 及以上，以及 Android 构建工具。首次准备工具需要网络；运行中的应用不依赖网络。

从仓库根目录执行：

```sh
python piano-android/prepare_tools.py
python piano-android/web/build.py
python piano-android/build_apk.py
```

未在 PATH 中配置 Java 时，可通过 `PIANO_JAVA` 指定 Java 可执行文件。JavaScript 构建使用仓库内附的 Babel，不需要安装运行时 npm 依赖。

`build_apk.py` 使用 `piano-android/signing/release.pk8` 和 `release.pem` 签名；密钥不随源码发布。自行构建必须在本机准备自己的签名，无法用不同签名覆盖安装官方 APK。脚本在密钥缺失时尝试通过 OpenSSL 创建签名，需先建立本地 `signing/` 目录并安装 OpenSSL。

输出文件位于根目录的 `deliverables/`。SDK 工具、签名、构建输出和临时文件均被 Git 忽略。官方 APK 和独立 HTML 通过 GitHub Release 发布。

核心检查可使用 Node.js 内置测试运行器，例如：

```sh
node --test piano-android/tests/*core.test.cjs piano-android/tests/song-learning.test.cjs
```

浏览器检查需要 Playwright 和 Chrome。部分脚本使用 Windows 的 Chrome 默认路径，其他系统需要按实际环境调整。开发过程与历史功能记录另存于 `开发与历史记录.md`。
