# 1.5.5 · 双手练曲版

用户可见变化见[完整更新说明](../../deliverables/五线谱识谱_1.5.5_更新说明.md)。本版基于 1.5.4，包名保持 `com.pianopractice.tablet`，versionCode 为 12，最低 Android 10。

## 练曲提示与数据

`song-guidance-core.js` 计算每只手的当前音和下一次起音，保留延续低音与同键双手目标。`song-guidance.js` 通过曲谱工作区提供的时钟、目标、输入状态和设置接口展示琴键与临时面板，不拥有独立播放或判定时钟。

MusicXML 解析保留原谱指法、谱表和谱号。多谱表按谱表分配默认手别；MIDI 按可调分界音估计。手别覆盖写入练习设置与学习条件，避免不同练习目标共用独立完成记录。内置指法仅为两首指定乐句人工编写。

辅助显示默认关闭，考核禁用。练习中看到的目标进入提示记录，整轮标为 assisted；关闭显示不会撤销已发生的帮助，也不会更改判定音。辅助练习不推进独立完成证据。默认手别设置保持旧学习记录键兼容。

## 布局与播放

正式布局采用谱面、小节位置、小节导航、播放工具与可收起琴键的网格；曲库和本轮设置按需打开。原有入门课程、专项训练、节奏及 USB MIDI 桥继续使用原模块。

循环选择按小节起止点操作；欣赏模式可在播放中调速并重算后续声音时间，练习和考核保持本轮条件固定。未提供音符级 A/B 循环、拖动把手或实际手指识别。

## 验证

- 核心与课程检查共 52 项通过，包括 MIDI、节奏、课程证据、曲谱判定、分段复习及双手预读边界。
- `song-guidance-ui.test.cjs` 覆盖原谱指法、上下谱表均为 F 谱号、实际/错键、收起琴键、辅助证据、考核禁用、循环选择和欣赏变速；覆盖 1280×800、1440×900、800×1280。
- 曲谱导入、离线钢琴采样、工作区、分段路线、专项一秒自动继续及键盘收起回归通过。
- APK 通过签名及对齐检查，HTML 与 APK 内嵌文件一致；30 个钢琴采样与许可声明完整。

真实安卓平板、实体 MIDI 钢琴与实际音频延迟尚未验证。桌面浏览器的触屏事件和模拟 MIDI 检查不等同于设备兼容性测试。
