## 已验证

| 项目 | 结果 |
| --- | --- |
| 核心、课程、提示、MIDI、节奏、曲谱与学习逻辑 | Node 核心检查 44 项通过 |
| 专项窗口边界 | 600、650、651、800、839 宽单列列表在前、参数在后；840 宽开始两区分离，无交叠 |
| 短高设置 | 960×480 / 960×600 内容窗口中关闭和完成保持可见；完成按钮中心命中正确 |
| 做题控件 | 600 宽返回、暂停、工具、提示、键盘开关命中区至少 48×48 CSS px；页头、反馈、键盘滚动区共用左边界 |
| 自动继续 | 屏幕琴键输入正确音，题号从 1/20 自动变成 2/20 |
| 收琴键 | 保留同一目标音；谱区高度增长。暂停中收琴键仍显示暂停层 |
| 导航与曲库 | 菜单打开/返回；曲名直接打开曲库；曲库/学习路线/高级设置切换；选曲返回谱面 |

| 节拍器 | 调速至 65 BPM、应用到训练、关闭面板；窄窗准备入口独立于正文滚动 |

测试宿主 `tests/layout-window.html` 只加载真实生产 HTML。运行 `tests/layout-checks.js` 可只读检查根宽度、专项区域交叠、设置主动作命中、做题触控尺度和左边缘对齐。测试宿主不打入 APK。

截图为桌面浏览器的生产页面或精确 iframe 内容窗口复现，不是 Android 实机截图。宿主可能比内容窗口更大；交付图裁掉宿主背景。独立截图评审后的改动包括曲库标题区改关闭图标、明确横滑提示、加强操作文字，以及隐藏弹层背后的谱面滚动条。
