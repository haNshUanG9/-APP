# 单机音乐入门课程建设方案

版本：讨论稿 1.0  
日期：2026-10-29  
适用产品：识谱练习室，离线 HTML 与 Android 平板安装版  
本次交付：课程与产品建设方案；本文中的新增课程、规则和数据结构尚未实现。

## 一、先确定用户要获得什么

目标用户是音乐基础薄弱、希望借助平板和实体键盘自学的初学者。需要同时照顾手边暂时没有实体琴、只能使用电脑或触屏的情形。

从现有使用反馈，可以确认以下需求：

- 希望练习有顺序、有重复，避免每次面对缺少关联的新题。
- 希望提示能帮助建立记忆，并在后续独立认出，而不是一直依赖答案。
- 希望接上实体琴，弹奏能够得到反馈。
- 希望练习有音乐感和成就感，长时间只操作软件答题容易枯燥。
- 希望布局清楚，知道接下来练什么，能够纯单机使用。

尚不能确认用户的实际识谱水平、听辨能力、每天练习时间和实体琴使用频率。因此这些不能写成既定事实，应通过简短的起点检查和实际练习记录逐步判断。

产品近期目标：**让用户在已学音域和节奏范围内，逐步独立完成一段简单音乐，知道自己的主要困难，并在隔一段时间后仍能再现。**

## 二、主要矛盾、次要矛盾与处理原则

### 2.1 当前主要矛盾

**用户希望独立弹出音乐，与音符、键位、听觉、节拍之间尚未建立稳定联系，以及软件缺少贯通这些能力的学习路线之间的矛盾。**

这里包含两端：用户有认知与操作的学习负担；产品需要提供合理的教学顺序。不能把学习困难全部归因为用户记忆不好。

主要矛盾的可观察表现是：专项题能答对一些，但换到短句就卡住；提示一收起就不确定；同时处理音高与节奏时顾不过来；练了很多题，仍不知道自己能弹什么。

近期资源优先投入：

1. 建立明确的能力先修关系。
2. 将听觉、识谱、键位和稳拍分别教会，再逐步组合。
3. 用固定短句与入门小曲承接专项练习。
4. 用无提示回测和受控变化检查学习，而非单靠累计题量。

### 2.2 次要矛盾

| 次要矛盾 | 用户表现 | 产品处理 | 优先级调整条件 |
|---|---|---|---|
| 需要重复与重复容易枯燥 | 同题反复后不愿继续 | 重复核心能力，交替使用听、看、弹和原曲应用；学习目标保持一致 | 若用户已学会但缺乏继续意愿，增加曲目应用和自主选择 |
| 题库覆盖不足与新内容增加负担 | 容易背题，换题又不会 | 明确母型、轻微变体和迁移题，按先修关系覆盖 | 当原题稳定而受控新题失败时，迁移成为当前重点 |
| 需要提示与形成提示依赖 | 看提示会，撤掉就错 | 提示逐层展开，辅助完成和独立完成分开记录 | 若困难主要来自提示依赖，先处理撤提示而非增加新音 |
| 知识点多与不知道怎样开始 | 反复调设置，课程之间跳转 | 首页只突出一项推荐和一个原因，保留自由入口 | 零基础尚不清楚操作方法时，导学是第一步 |
| 有趣的体验与可靠的反馈 | 有声音、有动画，仍不清楚哪里错 | 把反馈落到具体音、拍和片段，并给出下一步动作 | 反馈失真时，必须先修正评分 |
| 单机自学与缺少真人纠错 | 无法确认指法、手型和用力 | 提供离线动作示范与自查；明确自动评价范围 | 若出现疼痛或动作困扰，不用更多题目掩盖动作问题 |

**主次是动态的。**如果设备根本没有收到 MIDI，当前首要问题就是恢复有效输入；如果三个音都认不准，先修复音符与键位联系；如果都认识却总跟不上，就暂时固定音域，集中练时间组织。

### 2.3 按阶段识别当前的主要障碍

| 阶段 | 主要问题 | 推荐动作 | 暂缓增加 |
|---|---|---|---|
| 起点 | 不知道声音、琴键和谱面分别表示什么 | 短导学、操作示范、无压力试奏 | 倒计时、大量参数 |
| 单项建立 | 认不清位置、八度或基本拍点 | 小音组、参照、慢速稳拍 | 宽音域、多种新节奏 |
| 能力组合 | 单项会，合起来不稳定 | 固定两小节，先音高、再节奏、再组合 | 新调号、加速、复杂伴奏 |
| 学后应用 | 原句熟，换一点就不会 | 一次只变一个位置或一种关系 | 完全随机新题 |
| 长期保持 | 当天会，隔天忘 | 到期回测、针对性重学、回到原曲 | 无限制扩充新内容 |

上述判断允许“暂不确定”，样本不足时继续观察，不根据一次失误自动贴标签。

## 三、对现有代码的判断

### 3.1 可以继续利用的基础

- 音高专项已经有小音组、初次提示、无提示巩固、错题回测与本机续练。
- 已区分触屏和 MIDI 的学习证据，存在到期复习安排。
- 节奏已经有完整小节、稳拍、时值与休止、听后模仿、双侧输入和独立节拍器。
- 短句已有同句学习、撤提示、跟拍、小变体的阶段框架。
- 页面与离线运行基础已具备，近期无需另起一套应用。

### 3.2 会影响课程效果的具体缺口

| 代码现状 | 对教学的影响 | 方案要求 |
|---|---|---|
| 音高模型主要表示自然音 | 适合第一阶段，尚不能直接承担完整变化音教学 | 第一版限定自然音；变化音扩展另列数据模型任务 |
| 循序短句主要使用固定的六个起点和相同音序结构 | 容易练熟操作套路，音乐组织与节奏变化覆盖不足 | 增加人工编排的固定短句，分别标明教学目标与先修要求 |
| 节奏前两阶段主要使用首个母型，后续阶段按少数下标取题 | 条目数量不能代表实际教学覆盖，部分母型可能没有被练到 | 为每个母型设置稳定编号、教学次序和完成记录，自动验证覆盖 |
| 部分节奏单元存在内容重复或标题与题型不完全对应 | 学习者难以理解每个单元新增了什么 | 去重、校验概念标签，每个小课明确一个新难点 |
| 部分节奏阶段通过一次干净完成就推进 | 能说明本次完成，尚不足以说明保持和迁移 | 分开记录本次通过、隔题确认和延迟复习 |
| 节奏课程进度键包含训练速度 | 更换速度会形成另一组课程进度 | 内容进度与速度条件拆开；不同速度的表现证据仍分别记录 |
| 已有节奏模仿，但尚无系统的音高听辨课程 | 听觉参与不足 | 加入有参照的高低、方向和短旋律模仿 |
| 缺少分级完整小曲及片段关联 | 专项学习成果难以回到音乐中 | 将曲子、乐句、难点练习和回测关联 |

依据文件：`web/core.js`、`web/learning-core.js`、`web/study-core.js`、`web/study-ui.js`、`web/rhythm-core.js`、`web/rhythm-ui.js`、`web/midi-ui.js`。

## 四、循序渐进的课程路线

### 4.1 编排约束

1. 一节小课只增加一个主要难点。增加新音时，保持已学节奏；增加新节奏时，固定已学音组。
2. 章节可以包含多节小课。不能在一节课里把“学习 C、D、E”当成只增加一个知识点。
3. 单项不必练到完美才接触音乐。使用已学内容，尽早提供可完成的小片段。
4. 初期先连接听、看、弹，再引入专有名词；术语附在用户刚完成的体验后面。
5. 听出关系、看谱弹对和跟拍稳定分别记录，不互相代替。
6. 已有学习记录保留。通过起点检查的人可以跳过已会内容；新路线不要求老用户全部重学。

### 4.2 推荐章节

| 章节 | 主要矛盾与学习目标 | 内容顺序 | 学完可完成的任务 |
|---|---|---|---|
| 0：认识声音与键盘 | 尚未建立基本对象概念 | 黑键两枚/三枚分组 → 找 C → 定位中央 C4 → 试听高低 → 手指编号与简单操作示范 | 在键盘上找到参照位置，知道左右方向与音高的关系 |
| 1：两个音先认准 | 单音位置与具体琴键联系不稳定 | 沿用高音 G4 起点 → 加 F4 → 同音/异音 → 相对高低 → 两音交替 | 听、认、弹两个已学音，并完成一个不限时的小片段 |
| 2：三个音连起来 | 会认单音，关系记忆不足 | 加 A4 → 相邻上下行 → 重复音 → 固定两小节 | 无提示读完由 F4/G4/A4 构成的短句 |
| 3：拍子一直走 | 音的开始、延续与拍点容易混淆 | 固定四分拍点 → 二分延续 → 小节末休止 → 中间休止再进入 | 用已知单音或触区保持拍子，在休止后准确进入 |
| 4：第一段音乐 | 音高与节奏同时处理不稳定 | 同一句先不限时认音 → 单独练节奏 → 慢速合成 → 连起两句 | 独立完成一段四小节音乐，听回自己的演奏 |
| 5：扩大已知范围 | 换音组后定位不稳定 | 按先修关系分别加入 C4、D4、E4 → 与已知 F4/G4 连接 → 五指音组 | 完成八小节、固定手位的自然音小曲 |
| 6：低音与双手起步 | 两个谱表和两条声部相互干扰 | 低音参照 F3 → 附近音 → 左手独练 → 上下交替 → 少量同时起音 | 在右手熟句下加入简单、已学的左手声部 |
| 7：从熟句到新句 | 原句记住了，变化后无法独立应用 | 换一个音 → 换一个节奏位置 → 同技能的新乐句 → 隔日复现 | 在限定音域和节奏内，完成未练过的小变化 |
| 8：半音与全音 | 自然音经验不足以解释黑键和音程关系 | 相邻琴键 → 半音全音 → 升降还原 → 简单调号 | 理解黑键参与旋律，能在受控例子中认出变化音 |
| 9：和声与表现 | 能弹旋律，音乐层次不足 | 双音 → 三和弦与简单伴奏 → 强弱、连断和乐句 | 完成简单旋律加伴奏，并做基本的表现变化 |

说明：

- 第 0 章出现 C4，是键盘地理参照；不会自动视作用户已经认识 C4 的谱面位置。
- 第 1—4 章优先采用 4/4 拍和限定自然音，减少第一阶段的组合负担。
- 指法提示与练习动作可以提供，但 MIDI 按对音不等于证实用户用了指定手指。
- 八分音符先在一个拍位加入一对，练稳后扩大位置；不直接把整段全部替换成八分音符。
- 三连音、6/8 拍、十六分音符及更复杂的伴奏放在后续路线，分别设置先修条件。

## 五、一节课怎样教，怎样重复

### 5.1 小课流程

一节小课建议约 5—10 分钟，允许随时结束并保留位置；时间是设计参考，不作为强制计时。

| 环节 | 用户做什么 | 软件提供什么 | 记录方式 |
|---|---|---|---|
| 回想旧内容 | 完成少量到期或已学任务 | 先不显示答案，必要时自行展开提示 | 区分独立、辅助与未完成 |
| 认识一个新点 | 听、看、试一次 | 短示范、一个解释、一次操作 | 计为接触或辅助学习 |
| 固定内容巩固 | 重复同一小音组或节奏母型 | 位置、速度等无关条件保持稳定 | 积累独立正确证据 |
| 撤提示检查 | 不看答案再完成 | 保留求助入口，记录求助 | 不用辅助正确抵消独立错误 |
| 回到音乐 | 在已学短句中使用这一点 | 同句循环、分句示范与回放 | 检查应用表现 |
| 安排再遇见 | 完成后查看下次要练什么 | 给出一条下一步建议 | 保存隔题与到期回测任务 |

### 5.2 重复必须有目的

- **初识重复**：先把一个位置、一个拍点认清，不急于换题。
- **隔题回想**：答错后说明原因，再隔开其他已学内容检查。
- **同句重复**：保留原句，逐渐撤掉提示，再加入稳拍。
- **受控变化**：只改变一个已学维度，检查能否应用。
- **延迟回想**：下次打开时先检查，不把昨天的成绩直接当成今天仍会。

默认调度先沿用现有的错误后隔题回测及 1、3、7、14 天复习框架，新增课程复用调度思想，但建立各自的任务证据。这些间隔是初始产品规则，后续根据真实使用调整。

不能用未学内容凑间隔。如果没有合适的已学任务，结束当前块并留到下次；本次标为集中巩固，不虚构“已通过间隔记忆”。

### 5.3 “学过”与“会了”分开

建议使用以下状态：

`未接触 → 看过示范 → 辅助完成 → 独立完成 → 隔题确认 → 延迟复现`

受控变化另记为“已在新例子中应用”，避免将同题熟练直接等同于迁移。

初始门槛建议：

- 音高专项先兼容现有规则：每个目标至少 4 次独立正确；单目标集中练习的现有 6 次规则保留，尚未解决的错误回测不带入“已确认”。
- 新短句以每个小片段的独立完成为基础，再用隔开的复现和一次受控变化检查；可以尝试后续内容，但未确认项继续保留复习。
- 延迟复习影响“保持”状态，不要求用户必须等到第二天才能继续使用应用。
- 节奏精度阈值先保留为可配置初值。当前一拍 18% 的阶段判定不能直接宣传成音乐能力的标准。
- 整曲练习提供音高、起拍、连续性等分项反馈；不以“一次整曲零失误”作为所有后续课程的唯一入口。

上述门槛是待验证的开发起点，不代表已经验证的最优教学参数。

### 5.4 一节小课的具体例子：在 F4/G4 中加入 A4

先修条件：用户已有 F4/G4 的独立识别证据，能够在选定慢速下完成四分稳拍。若不满足，先返回对应任务。本课主要解决“新增相邻音与原音组的联系”，保持谱表、八度、拍号和速度不变。

1. 先不显示答案，分别检查一次 F4/G4。若旧音明显不稳定，本次改为旧内容巩固。
2. 以 G4 为参照，试听 G4→A4，再演示谱面向上相邻一步和对应琴键。初次接触记为辅助学习。
3. 用户在 F4/G4/A4 中辨认目标，按小块重复，提示逐渐撤去；区分“听出方向”和“看谱找到键”两项任务。
4. 遇到错误先讲清具体位置，之后使用其他已学内容隔开再检查，不在答案仍显示时要求立即重按并算作独立正确。
5. 新音稳定后，进入固定两小节：`G4 F4 G4 F4 | G4 A4 F4 G4`，全部为已学的四分节奏。先允许停下来认准，再按原有慢速完成。
6. 独立完成原句后，在后续小块中将一个已学音的位置改变一次，检查是否仍能认出；原句与变体分别记录。
7. 结束时说明本次完成到了哪一步，并保存下次回想任务。尚需帮助时允许继续练，但不显示“已经牢牢记住”。

如果此时用户音高都正确却跟不上拍子，当前主要困难已经变成组合负担：停止加音，提取一小节练习节奏后回到原句。界面装饰、额外曲目和更快速度暂不进入本课。

## 六、把题库设计成有顺序的内容

### 6.1 三种内容承担不同任务

| 内容 | 用途 | 生成规则 |
|---|---|---|
| 固定母题 | 初识、重复、同题纠错 | 人工编排，稳定编号，失败保留原题 |
| 轻微变体 | 检查是否掌握当前关系 | 显式列出变化点，只使用已学内容 |
| 迁移题 | 在新片段中检查应用 | 受限生成或人工编排，验证音域、节奏与先修要求 |

随机生成主要用于已学技能的变化练习。新知识第一次出现要有明确示范和固定例题。

每个母型都需要实际覆盖记录，不能只用“题库有多少条”展示丰富程度。重复的音序或节奏不能因编号不同重复计算。

### 6.2 每条课程内容的最低字段

| 字段 | 含义 |
|---|---|
| 稳定 ID 与内容版本 | 升级后能识别同一题，避免重启或换版本丢失关系 |
| 学习目标与先修能力 | 知道本题教什么、为什么现在出现 |
| 唯一主要新难点 | 防止同时引入新音、新拍号和新动作 |
| 音高、节奏、声部与时值 | 用于谱面、示范与评价，保持同一份内容来源 |
| 示范和分级提示 | 同一知识有听觉、谱面或键盘解释 |
| 关联原曲与片段 | 知道练完要回到哪段音乐 |
| 母题与变体关系 | 知道变化了什么，以及允许变化的范围 |
| 输入方式与可评价能力 | 明确触屏与 MIDI 分别能证明什么 |
| 阶段规则及复习规则 | 区分辅助、独立、间隔和延迟证据 |

内容上线前检查：小节时值平衡、音域合法、无未教符号、示范与谱面一致、变体只改变允许项、所有必学母型可达。

### 6.3 第一批内容的具体范围

第一版只实现第 0—4 章的完整学习链，建议分配如下：

- 导学 4 节：黑键分组与 C、音的高低、谱面与键位、拍子与时值。
- 音高与关系 4 节：G4、加入 F4、加入 A4、三音关系巩固。
- 节奏 4 节：四分稳拍、二分延续、末尾休止、中间休止再进入。
- 有参照的听觉练习 3 类：相同/不同、高低与方向、两至三音跟弹；穿插到上述小课，不要求先修完一条独立听觉长课程。
- 人工编排短句 6 条：先两音、再三音；先固定四分、再加入已学二分或休止。每条设置一个轻微变体。
- 第一批入门小曲 3 首：每首 4—8 小节，使用当时已经学过的内容，至少有一首只依赖两至三个音；可采用原创短曲。

这组数量用于限定制作和验证范围。能否上线取决于课程链条完整及内容质量，不取决于凑够条数。

## 七、三个核心模块的建设要求

### 7.1 导学：先体验，再解释，再操作

每节导学只回答一个问题，例如“为什么向右弹，音会更高”。

推荐结构：播放两个音 → 演示琴键位置 → 用户自己试 → 给一个判断任务 → 把结果连接到后续识谱或听辨练习。

说明尽量配声音和图示。可重复播放、可跳过、可在困难时返回。导学不要求记住全部术语才允许碰琴。

### 7.2 听觉：有参照，不以绝对音感为前提

先比较差异，再辨认方向，之后模仿短音组。听音跟弹提供起始参照音和已知音域，允许先慢慢找，再逐步检查节奏。

不同阶段分别判断：

- 是否听出关系。
- 是否在已知琴键中找到对应音。
- 是否记住短音组顺序。
- 是否按既定拍子复现。

一次不同时测四项。界面播放状态和提示不得提前泄露待判断答案。无声、音频未启动等情况要提示检查声音，不记为听辨错误。

### 7.3 小曲：分句练习与专项互相连接

每首小曲提供完整示范、分句示范、固定片段循环、慢速练习、撤提示、受控变体和实际演奏回放。

练习顺序：

`听完整句 → 第一小段认音 → 同段节奏 → 慢速组合 → 下一小段 → 连接两段 → 独立复现`

错误发生在具体位置时，先确定是音高、八度、起点、时值还是声部问题，提取对应片段练习，再返回原曲。

“小曲练习”与“严格时值专项”使用不同评价规则。连奏、断奏、踏板和曲目表达要求需要显式标注；不能将所有音符都按“必须按住满时值”的教学规则评价。

## 八、发现主要困难后，怎样安排下一步

| 观察到的证据 | 暂定困难 | 首选处理 | 不应立即做什么 |
|---|---|---|---|
| 提示后正确，撤提示持续错误 | 提示依赖或位置记忆尚未形成 | 回到参照与线间关系，隔题再认 | 直接提高题量和音域 |
| 音名正确，常错一个八度 | 八度与键盘位置联系不足 | 练中央 C 与黑键分组，再比较同名异八度 | 把所有错误统称为识谱慢 |
| 不限时认音稳定，跟拍时失误增加 | 同时处理负担较高 | 固定原句，降速、缩短片段，分开练节奏 | 加新音或换新曲 |
| 起点稳定，专项长音经常提前结束 | 对延续的理解或控制不足 | 固定单音练持续与休止，再回片段 | 据此判定真实演奏连奏错误 |
| 原句稳定，小变体失败 | 关系应用不足 | 比较原句与一个变化位置 | 大量完全随机出题 |
| 隔天错误增加 | 保持不足 | 安排已学内容回测和重学 | 仅按昨日累计正确次数跳过 |
| 多种任务突然异常，或出现断线 | 输入/音频条件可能变化 | 先验证连接、声音与时间条件 | 直接扣分或推断学习退步 |

反馈采用“位置＋现象＋下一步”表达，例如：“第二小节第 3 拍进入偏晚。先把这一小节降速练两次，再放回原句。”

同一片段连续受挫时，主动提供更小片段或提示，不无限增加加练。一次失误保留为观察证据，需有重复表现才提高某类练习权重。

## 九、单机与设备边界

### 9.1 完全离线所需内容

课程、谱面、示范音频或本地合成、题库、规则、回放和学习记录均保存在设备上；不依赖账号、云端服务或联网生成内容。

第一版可以沿用本地合成声音。若试听反馈显示音高不易分辨或音色影响学习，再评估内置少量钢琴采样，不将大音源库设为课程建设前提。

### 9.2 两种输入保持可用，但证据分开

| 场景 | 可完成的任务 | 自动评价边界 |
|---|---|---|
| HTML＋鼠标/触屏 | 导学、听辨选择、识谱、触屏找键、节奏点击和短句体验 | 不能证明实体琴手位、指法或双手动作已经掌握 |
| Android＋USB MIDI 实体琴 | 以上任务，以及实体琴上的找键、跟弹与声部配合 | 可评价收到的音和时间，无法看到具体手指、手型和身体用力 |

当前 HTML 不具备新增的浏览器 MIDI 接入。方案第一版沿用 Android 原生 USB MIDI；浏览器 MIDI 是独立的后续兼容任务。

力度值可用于同一设备上的相对强弱练习，不能直接等同真实音量与音色质量。踏板状态、手指松键与声音持续应分别处理。

### 9.3 本机记录与恢复

- 保留原数据，采用带版本的增量迁移；不清空原学习档案、错题与报告。
- 保存课程位置、片段、提示使用、待回测任务和内容版本。
- 内容进度与速度、输入方式下的表现证据分开。降低速度后不丢失“学过哪些内容”，也不把低速成绩冒充高速掌握。
- 新增听觉、曲目和片段证据，避免复用一个音高正确次数代表所有技能。
- 继续支持本地导入导出。设备时钟改变不能直接让记忆等级升级。
- 更新后优先提供续练和简短起点检查，不默认将所有用户送回第一课。

## 十、界面怎样服务学习

现有新界面作为基础，近期主要调整任务组织。

- 首页突出“今天主要练什么”“为什么推荐”“练完能做什么”，每次给出一项主任务。
- 其余入口保留自主选择，不把主线做成无法跳出的长队列。
- 课程图显示当前目标、先修项和应用曲目。辅助完成与独立完成用文字区分。
- 训练时突出谱面、当前片段和输入区；参数放在准备阶段设置。
- 结果页只优先展示当前主要困难和一个动作，详细报告可以展开。
- 没带琴时提供适合触屏完成的任务；切回实体琴后保留相关学习内容，并单独检查实体琴表现。

成就反馈围绕实际能力，例如“第一次无提示读完两小节”“隔天仍能复现”；避免用题量、连续签到或满屏奖励掩盖掌握不足。

## 十一、分期实施与验收

### P0：先保证内容顺序和证据可靠

交付：能力与内容编号、现有母型清理、母型可达性检查、内容进度与速度条件的拆分设计、评分边界整理、旧数据迁移方案。

验收：

- 必学母型能按既定顺序被实际练到，重复母型不重复计数。
- 失败重练原题；换阶段或变体时能够说明变化点。
- 调速不会误清空内容进度；不同速度的表现仍可分别查看。
- 用提示、暂停、取消触点和设备异常的证据处理符合各自规则。
- 原有学习、提示、节奏、MIDI 回归检查通过。

### P1：完成第一条入门学习链

范围：第 0—4 章、三类基础听觉任务、固定短句和 3 首入门小曲。

交付：导学 → 小音组 → 关系听辨 → 基础节奏 → 固定片段 → 第一段音乐 → 回测的完整流程。

验收：

- 新用户能理解第一步如何操作，做错后知道可以怎样继续。
- 新课不引入未教音符或节奏，必要操作不被界面遮挡。
- 短句中的错误能回到对应难点，练后能返回原句。
- 首次接触、辅助完成、独立完成、隔题确认及到期复现分别记录。
- 退出、重启、导入导出之后保留课程与待回测状态。
- 所有课程资源离线可用；音频不可用时不会把任务失败记成听力错误。

### P2：扩展自然音音乐应用

范围：五指音组、低音参照、分手到合手、更多人工编排的入门曲，以及更完整的关系听辨。

验收重点：换一段同难度音乐后仍能使用所学能力；不会只提高原曲熟练度。

### P3：扩展音乐语言

范围：半音全音、变化音与简单调号、音阶、三和弦、简单伴奏和基本强弱连断。

先完成支持变化音的音高表示、谱面、答案、学习键和迁移设计，再写对应课程；不只在现有自然音界面上增加几个按钮。

### 后续深化

三连音、6/8 拍、十六分音符、更多表情和踏板应用，根据前几期真实困难安排。此阶段再决定是否需要更大的曲库、更细的演奏评价和更好的本地音色。

不在第一版增加账号、排行榜、云端生成题目、复杂作曲工具，也不一次铺开全部调号与高难节奏。

## 十二、怎样验证方案确实帮助学习

软件测试验证“行为和数据是否正确”；学习效果需要真实练习观察。两者分开报告。

### 12.1 重点观察指标

| 指标 | 检查的问题 |
|---|---|
| 撤提示后的独立表现 | 提示是否帮助形成记忆 |
| 原句与受控变体的差异 | 是否形成应用能力 |
| 下次练习的首次表现 | 是否保持，而非只在本轮熟练 |
| 完成第一段音乐时需要的帮助 | 主线是否真正贯通 |
| 错误集中在哪些技能和位置 | 推荐是否抓住主要困难 |
| 连续失败及中途离开的环节 | 内容是否超前、解释是否不足 |
| 触屏与实体琴表现差异 | 软件成绩能否迁移到实体琴 |

先用少量真实初学者或用户自己的连续练习记录检查：无提示任务、受控变体、后续日期复现三类证据。小规模观察用于调整路线，不宣传统计上已证明的普遍效果。

### 12.2 内容、交互和迁移检查

- 导学之后的题目确实只要求刚教过的知识。
- 曲目、分句、示范、提示和评分来自一致内容。
- 听辨过程中没有通过高亮或文字提前泄露答案。
- 固定短句不因刷新、切页或失败被重新随机生成。
- 所有目标母型和变体都有可达性与覆盖检查。
- 新数据往返、旧数据迁移、课程断点恢复可靠。
- MIDI 断线、触屏取消、音频未启动和提前结束分别正确处理。
- 横屏、竖屏和无实体琴场景下都能完成相应任务。

## 十三、实施决策

近期执行顺序为：**P0 内容与证据整理 → P1 第一条入门学习链 → 根据真实困难扩展 P2/P3。**

第一阶段的完成标志是：用户能够理解并独立完成一段由已学内容构成的音乐，失败时得到针对当前主要困难的帮助，过一段时间后还能回来检查和继续。

遇到范围冲突时，优先保证教学顺序、重复回想、音高与节奏的逐步组合以及学习后的音乐应用。曲库规模、更多参数和更复杂的功能按其对这些目标的实际帮助排序。
