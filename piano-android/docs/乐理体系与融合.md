# 乐理体系与APP融合

1.6.0将音程、和弦、声部与织体放进“查阅／短恢复→实践→换例→回顾→原曲应用”的连续路径，目标是让快速上手与理解乐理互相促进。

主菜单及今日／专项入口打开同一`theoryPage`，复用`PianoHost`路由、主备份、`PianoAudio`和原生`PianoInput`。内容18概念；深度实践集中于I02、C01、C02、C06、T01/T02/T03，进阶内容只查阅。探索保留22类结构、多义／条件候选、动态续接、具体配音与链条编辑。

## 模块

- `theory-data.js`：主db.version6下的theory规范化、存储适配、曝光裁切摘要与恢复快照。
- `theory-chord-core.js`、`theory-input.js`：22类和弦与独立物理／踏板／点选输入。
- `theory-content/materials/curriculum/learner-core/player`：概念、真实时间事件、题池、分维评价与可取消播放。
- `theory-shell/learner-ui/explorer-ui/ui`：作用域内组件、共享顶栏与页面生命周期。没有iframe、第二音源bank或独立Web MIDI授权。
- `song-ui.js`的`captureTheoryContext/restoreTheoryContext`：等待曲库ready，以同songId恢复；保留内存run并标辅助／中断，重载只准备态。考核运行中API拒绝知识帮助。

源码以已验独立教材／和弦实例为基础提取，原交付实例未修改。教学评价分音程级数与半音、和弦结构与低音、事件起音／时值／角色；点选与拍格编排不冒充连续演奏。

## 记录与备份

查阅与恢复分路。提示、答案、材料曝光、来源、实际间隔分别记录；熟悉材料无提示回忆不冒充未见迁移。初始即时辅助窗口10分钟、回顾1／3／7天是可调整策略，不是学习效果保证。

最多保留500近期事件、512详细曝光，另保留8192位保守曾见摘要与被裁辅助窗口、各维last/due和计数。摘要可能把未见判为已见、把独立判为辅助，不能反过来清除已曝光事实而制造独立证据；不称精确无限档案。当前能力材料池规模远小于任意无限输入。

基础练习导出包含theory；版本2–5旧备份保留现有theory，版本6替换。曲谱库仍单独备份。保存先检UTF8字节数及5MB上限，native成功确认后写镜像，失败回滚。缺旧签名不构建替代证书。

## 验证边界

纯教材／排程／数据、浏览器真实操作、模拟原生MIDI、Java解析、Android构建与包核验分开记录。浏览器CSS像素不等于Android dp实测；没有实体平板与USB设备时不宣称真机或长期学习效果通过。
