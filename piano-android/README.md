# 五线谱识谱

本目录为安卓平板离线识谱练习应用的源码。应用用于循序认音、音高专项、短句读谱、节奏训练和导入曲谱后的分段练习，支持 USB MIDI 实体琴与屏幕琴键输入。

当前版本：**1.5.7**。按简约 B 布局重排练曲、专注看谱和专项做题：大谱面、单条演奏控制栏、临时设置，黑色音符与琴键左右手辅助。用途与功能见[项目介绍](../README.md)、[基础用户说明](../deliverables/五线谱识谱_1.5.4_完整用户功能说明.md)及[本版更新说明](../deliverables/五线谱识谱_1.5.7_更新说明.md)。

构建方法见[开发说明](docs/构建说明.md)。
