# 五线谱识谱

本目录为安卓平板离线识谱练习应用的源码。应用用于循序认音、音高专项、短句读谱、节奏训练和导入曲谱后的分段练习，支持 USB MIDI 实体琴与屏幕琴键输入。

稳定版本为 **1.6.0**，当前为 **1.6.1 测试版**：新增 MSCZ/MSCX 直接导入、原文件与版本保留、v3 ZIP 曲库备份、调号影响认音与记忆迁移。沿用原签名升级，当前 APK 与此前本地验收包相同。保留乐理与和弦、识谱、听音、节奏、黑色大谱面和可收琴键。

用途与功能见[项目介绍](../README.md)、[基础用户说明](../deliverables/五线谱识谱_1.5.4_完整用户功能说明.md)及[1.6.1 更新说明](../deliverables/五线谱识谱_1.6.1_更新说明.md)。未验证的记谱片段提供定位与局部能力限制；真实安卓 USB 与系统文件读写仍待实机测试。

构建方法见[开发说明](docs/构建说明.md)。
