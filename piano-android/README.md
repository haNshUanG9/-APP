# 五线谱识谱

本目录为安卓平板离线识谱练习应用的源码。应用用于循序认音、音高专项、短句读谱、节奏训练和导入曲谱后的分段练习，支持 USB MIDI 实体琴与屏幕琴键输入。

当前版本：**1.5.5**。新增双手当前/下一组提示、原谱指法、可收起琴键、小节循环选择和临时练习设置；辅助练习与独立完成分别记录。用途与功能见[项目介绍](../README.md)、[基础用户说明](../deliverables/五线谱识谱_1.5.4_完整用户功能说明.md)及[本版更新说明](../deliverables/五线谱识谱_1.5.5_更新说明.md)。

构建方法见[开发说明](docs/构建说明.md)。
