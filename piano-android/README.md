# 五线谱识谱

本目录为安卓平板离线识谱练习应用的源码。应用用于循序认音、音高专项、短句读谱、节奏训练和导入曲谱后的分段练习，支持 USB MIDI 实体琴与屏幕琴键输入。

当前版本：**1.6.0**。新增乐理与和弦：18概念查阅与定点恢复、音程／和弦／声部／织体实践、22类和弦分析与实际配音续接。曲谱查阅后可回原段，主备份包含乐理。保留识谱、听音、节奏、黑色大谱面、可收琴键和临时菜单。用途与功能见[项目介绍](../README.md)、[基础用户说明](../deliverables/五线谱识谱_1.5.4_完整用户功能说明.md)及[本版更新说明](../deliverables/五线谱识谱_1.6.0_更新说明.md)。

构建方法见[开发说明](docs/构建说明.md)。
