# 【科技改变生活】五线谱识谱练习软件

一款面向安卓平板的离线钢琴入门与识谱练习软件，帮助用户从认识五线谱，逐步过渡到找键、短句跟弹和分段练曲。当前版本为 **1.5.9**。

- **循序入门**：6 章、18 课，从参照音、音区、时值和休止开始学习。
- **专项巩固**：练参照音、易混音、加线音与琴键到谱面的对应关系，提供分层记忆提示。
- **独立听音**：相同与方向、一步与跳进、三音轮廓、乐句比较、有参照找键和听后复现；练习、独立检查与延后回测分别记录。
- **短句与节奏**：将单音连成乐句，配合六类节奏训练和可自定义的节拍器。
- **导入练曲**：支持 MIDI、MusicXML、MXL，提供认音、跟拍、考核和欣赏模式，以及分段学习与困难拆练。
- **实体琴输入**：通过 USB MIDI 连接钢琴或键盘，判断音高与起拍；也可使用屏幕琴键。
- **复习与记录**：记录错音、提示使用和节拍表现，安排间隔复习，支持本机备份。
- **练琴调整**：普通练习可就地调整速度、手别与选段，开始新的尝试后可回原段；谱面可直接点选起止小节，考核条件仍固定。
- **平板适配**：按可用窗口切换专项单双栏，设置面板固定完成操作；曲名直达曲库，曲库、学习路线和高级设置分开显示。
- **平板看谱**：简约谱台布局、专注放大与完整谱行，黑色音符、可收起键盘；左右手颜色用于琴键与标签，内置可离线使用的钢琴采样。
- **双手辅助**：分别预读左右手当前音与下一组，显示原谱或部分内置编配的指法，支持另一声部伴奏；辅助完成与独立练习分别记录。

适用于 **Android 10 及以上**。无需账号，安装后可离线使用。
